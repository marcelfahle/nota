# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone taking part in issues, pull requests, discussions and chat is expected to follow it.

## In short

- Assume good intent, but be direct and specific.
- Focus discussion on code, product behavior, and evidence.
- Share feedback that is actionable and respectful.
- Help keep the repository welcoming to contributors with different backgrounds and experience levels.

Harassment, personal attacks, discriminatory language, intimidation, trolling, publishing private
information, and bad-faith disruption are not acceptable.

## Enforcement

Report unacceptable behavior to hello@withnota.com. Reports are handled privately by the
maintainers at No Rules Software SL, following the enforcement guidelines of the Contributor
Covenant. The maintainers may edit, remove, or reject contributions and discussions that violate
this code of conduct.
